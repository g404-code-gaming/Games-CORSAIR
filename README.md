# Les petits défis Garage404 : fichier autonome

Ouvre `les-petits-defis-autonomes.html` dans un navigateur compatible. Il contient les deux jeux, leurs dix modèles ou parcours, le robot et tous les styles. Aucun autre fichier n'est nécessaire pour jouer ; `assemblage.json` sert seulement à vérifier les empreintes de cette version.

## Avant le départ

1. Enregistre le fichier HTML dans un dossier facile à retrouver.
2. Ouvre-le avec le navigateur qui servira pendant le voyage. Un aperçu de pièce jointe n'est pas forcément un navigateur capable de faire tourner le jeu.
3. Coupe le réseau et vérifie que les deux jeux s'ouvrent et que les boutons fonctionnent.
4. Conserve ce fichier au même endroit. Les sauvegardes restent dans ce navigateur et peuvent dépendre du chemin du fichier.

Les deux blocs explicatifs de préparation et d’aide aux parents ont été retirés du jeu à la demande de Garage404. Les éléments nécessaires pour jouer restent inclus dans le fichier. Il n'y a ni installation, service worker, dépendance externe, publicité ou compte. Recevoir ou transférer le fichier peut nécessiter une connexion.

Certains téléphones ou réglages de sécurité bloquent les fichiers HTML locaux. Le contrôle de cette livraison utilise Chrome sur ordinateur, y compris avec le réseau coupé ; il ne garantit pas tous les appareils. La version web, si elle est fournie séparément, possède son propre mode de préparation et ne partage pas automatiquement les sauvegardes de ce fichier.

## Jouer

- **Dessine en pixels** : choisis une couleur, touche les cases pour reproduire le modèle et clique sur « Vérifier ». Le modèle suivant apparaît après une réussite vérifiée. Tu peux aussi créer un dessin libre.
- **Guide le robot** : ajoute les flèches dans l'ordre et teste le programme. Les flèches indiquent une direction sur la page. Les petits décors clairs sont traversables ; les murs hachurés arrêtent le robot. Touche une instruction pour la retirer.
- Tu peux changer de jeu sans effacer ta partie. Les remises à zéro demandent confirmation. Quand le stockage du navigateur échoue, un message l'indique : la session reste jouable mais sa sauvegarde n'est pas garantie.

Aucun dessin ou résultat n'est envoyé à un serveur. Déplacer ou renommer le fichier, changer de navigateur, utiliser le mode privé ou effacer ses données peut faire perdre l'avancement. Les parties ne sont pas transférées entre appareils.

## Affichage

Le thème sombre est proposé au premier accès. Le bouton « Thème » alterne avec le thème clair ; ce choix reste dans le navigateur lorsque son stockage est disponible. Le slogan fourni est centré sous le logo. Les couleurs des modèles et des cases à remplir restent identiques dans les deux thèmes.

## Liens et choix du jeu

Le logo et la bulle « Découvrez nos activités numériques à partir de 6 ans ! » ouvrent https://garage404.com/ et demandent une connexion. Le bouton « Choisir un jeu », en bas de page, revient au menu des deux activités sans quitter le fichier.
